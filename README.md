# Personal Portfolio Website

Responsive portfolio built with HTML, CSS and JavaScript (no frameworks).
Live site: https://developwithmahendra.github.io/personal-portfolio/

## Run it
Open `index.html` in any modern browser. No build step or server is needed.

## Files
- `index.html` – page structure and content
- `css/style.css` – design tokens, layout, animations, responsive rules
- `js/script.js` – menu, active link, typing text, project rows, form validation
- `screenshots/` – desktop and mobile captures

## Make it yours
Replace "Aarav Sharma", the bio, skills, projects and links in `index.html`.
Colours and fonts are CSS variables at the top of `css/style.css`.
